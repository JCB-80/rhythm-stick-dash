프로젝트 폴더 내 @SPEC.md 명세서('0. 최우선 절대 규칙' 포함)와 @assets/ 하위 폴더의 PNG 에셋 31종을 확인해줘.
현재 프로토타입 단계이므로 프레임워크(순수 HTML/CSS/JS + Three.js CDN), OAuth 클라이언트 키(Local Mock 자동 계정 생성), 백엔드/세션(localStorage 저장), 랭킹 시스템(내 점수 + 29인 AI 그룹 실시간 통합 리더보드 & Cloud 어댑터 분리)에 대해 나에게 절대 역질문하지 말고 바로 전체 게임을 완성해줘!

- 로그인 규칙: 아이디/비밀번호 입력창이나 회원가입 폼은 절대 만들지 말고(ui_01_login_title.png 레퍼런스 좌측의 ID/PW 칸도 무시), @assets/sprites_login/ 안의 카카오·네이버·구글·애플·게스트 5개 원터치 버튼 중 아무거나 클릭하면 첫 방문 시 자동으로 계정이 생성되어 바로 캐릭터 선택으로 넘어가게 해줘.
- 이미지 규칙: 안티그래비티 자체 이미지 생성은 쓰지 말고 @assets/ 폴더 안의 PNG 파일들만 그대로 연결해서 '리듬 스틱 대쉬'의 5버튼 로그인 → 3인 캐릭터 선택 → 곡/난이도 로비 & 30인 주간 랭킹 → Three.js 3D 갈림길 네온 트랙 & Web Audio API 사운드 싱크 본게임 → S+ 결과 화면까지 끊김 없이 플레이되도록 만들어줘.
- 다국어(i18n) 필수 규칙: @locales/i18n.js 언어팩과 @assets/sprites_i18n_frames/ 안의 무문자 버튼 프레임·지구본 아이콘(icon_lang_globe.png)을 연결해서 한국어(ko)·영어(en)·일본어(ja)·중국어 번체(zh-TW)·스페인어(es) 5개 국어가 기기 언어 자동 감지 및 상단 지구본 드롭다운 클릭 한 번으로 로그인부터 인게임·상점·랭킹·대사까지 전체 실시간 전환되게 구현해줘! (해외 언어 선택 시 Google·Apple·게스트 버튼을 상단 우선 정렬해줘.)
