# 리듬 스틱 대쉬 (Rhythm Stick Dash)

순수 HTML5 + CSS3 + Vanilla JavaScript + Three.js r128 + Web Audio API 기반 3D 리듬 러너 프로토타입입니다. 별도 앱 빌드는 필요하지 않습니다.

## 실행

`실행하기_StartGame.bat` 또는 다음 명령으로 정적 서버를 실행하세요.

```bash
python -m http.server 8080
```

브라우저에서 `http://localhost:8080`에 접속합니다. Three.js CDN이 차단되면 동일한 r128의 동봉 파일로 자동 대체됩니다. `file://` 실행도 지원하지만 이미지 텍스처는 캔버스 폴백을 사용합니다.

## 플레이

- 4곡, 4난이도, 카이·루나·아리아의 기존 스킬, 콤보·피버·실드, Y자 STANDARD/RUSH 분기를 유지합니다.
- 차선 이동: A/D 또는 좌우 방향키. 탭: Space/J/K/F. 스와이프: Shift/S/L/Q/E/위 방향키.
- 원래의 인접 차선 판정 보조와 공통 스와이프 버튼을 유지합니다. 캔버스 드래그 한 번으로 두 노트를 동시에 판정하던 오류만 제거했습니다.
- 수동 피버: Enter/V 또는 터치 버튼. 자동 발동은 설정에서 변경합니다.
- Escape 또는 일시정지 버튼으로 멈춥니다. 백그라운드 전환 시에도 자동으로 멈춥니다.
- 설정의 판정 보정은 -250~250ms입니다. 양수는 늦은 입력을 허용하는 방향입니다.
- 사용자 오디오: 최대 25MB, 8초~3분. 피크 분석에 실패하면 135 BPM의 대체 격자를 사용합니다. BPM을 실제 분석한 것으로 표시하지 않으며, 사용자 곡은 공식 내장곡 주간 합산에서 제외합니다.

## 계정·기록·보상 범위

- 소셜 버튼은 **로컬 모의 로그인**입니다. 실제 OAuth·서버·다른 이용자와 연결되지 않습니다.
- 리그는 본인과 29명의 AI로 구성된 연습 리그입니다. 고스트 HUD도 AI 진행률 시뮬레이션입니다.
- 주간은 UTC 월요일에 바뀝니다. 내장곡별 주간 최고점의 합산과 곡·난이도별 순위를 제공합니다. 개인 최고점은 주간 초기화와 무관하게 유지됩니다.
- 주가 끝난 뒤 기록을 정산합니다. 상위 10명은 다음 리그로 승급하고 500코인을, 그 외 참여자는 200코인을 한 번 수령합니다. 21~30위는 한 단계 내려가며 브론즈~다이아 범위로 제한됩니다.
- HP가 0이 되어도 기존처럼 곡 끝까지 계속 플레이할 수 있습니다. 클리어 보상·주간 참가 기록은 HP가 남고 가중 정확도 65% 이상인 결과에만 적용됩니다. 전부 놓친 결과에 A등급·기본 보상을 지급하던 오류를 수정했습니다.
- 결과에 표시되는 코인·EXP·BEAT CORE를 실제로 저장합니다. 새로운 레벨·성장·소비 시스템은 추가하지 않았습니다.
- VIP는 **무료 체험**으로 코인 2배와 오라를 확인하는 기능입니다. 실제 결제나 광고 SDK는 없습니다. 무료 체험 보너스는 UTC 하루 한 번입니다.
- 기존 v5 UID·닉네임·코인·설정·개인 최고점은 v6 프로필로 이전합니다. 이전 키는 지우지 않습니다. 날짜 정보가 없는 과거 누적점은 새 주간 점수로 이월하지 않습니다.
- 저장소 차단·용량 부족 시 탭 내 메모리로 계속 플레이하고 경고합니다. 이 경우 탭을 닫으면 새 진행 기록은 사라질 수 있습니다. 클리어 기록과 보상은 하나의 프로필에 함께 저장하며 동일 세션의 중복 지급을 방지합니다.
- 브라우저 기록은 사용자가 변경할 수 있습니다. 실서비스 구매·공식 경쟁에는 서버 인증, 영수증 검증, 서버 권한의 점수·재화 처리가 별도로 필요합니다. 키만 추가한다고 클라우드 서비스가 활성화되지는 않습니다.

## 검증

```bash
node --test tests/regression.cjs
```

선택적 실제 Chromium 스모크 검사:

```bash
npm install --no-save playwright
npx playwright install chromium
node tests/browser.cjs
```

설치된 별도 Chromium은 `RSD_BROWSER_EXECUTABLE`로 지정할 수 있습니다. 브라우저 검사는 CDN 차단 폴백, 화면 크기·언어 전환, 일시정지·재개, 피버, 결과·랭킹·재도전, 반복 재도전 리소스를 확인합니다. 검증 범위와 한계는 [TESTING.md](TESTING.md)를 참조하세요.
